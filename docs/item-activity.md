# Item activity

Open Item activity from any lot to see who changed it, when and through which workflow. Recorded changes expand inline. History pages through all events and can be closed without losing unsaved details underneath.

The server projects known fields rather than forwarding arbitrary audit payloads. Current cost permission applies recursively, including historical mixed records. Unknown events retain actor/time metadata without invented values. Existing pricing history remains the place for exact saved-plan review and Undo.

Package 0.13.0 passes 19 focused workspace tests and the mobile browser journey in `verification/item-activity.json`. TypeScript, lint, build, formatting and installed-source checks pass. No migration is needed.
